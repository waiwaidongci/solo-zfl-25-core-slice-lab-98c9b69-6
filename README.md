# 岩芯切片任务台

面向实验室技术员的岩芯切片制片任务台：一次登记一个批次的多张切片与负责人，切片按项目规定的
**五道制片工序**（取样 → 切割 → 研磨 → 染色 → 封片）依次推进，逐序记录操作人、时间和依据；
制片完成后观察并写「合格 / 不合格」结论；不合格切片登记缺陷、作废原因并安排替代切片，
替代切片从第一道工序重新做起；同一批次存在未观察、不合格或未补替代切片时不能交付。

## 运行

```bash
npm start            # 默认 http://localhost:3025
node demo.mjs        # 一键自动走通全部业务场景（使用独立端口与数据文件）
```

环境变量：`PORT`（默认 3025）、`DB_FILE`（默认 `data/core-slices.json`）。
首次启动若检测到旧版数据文件，会自动备份为 `*.v1-<时间戳>.bak.json` 并重建示范批次。

## 页面（任务台）

- **左侧**：批次登记表，一次录入多张切片（编号 + 负责人，负责人留空继承批次负责人）。
- **顶部**：批次/切片数、制片中、待观察、待处理缺陷、可交付、已交付统计。
- **待处理缺陷面板**：所有批次中未闭环的不合格切片（缺陷、作废原因、替代片及替代片当前状态），点击可跳转。
- **批次卡片**：每批五序进度条（已完成工序/总工序）、各状态计数、交付门禁原因、
  **下一负责人/待办聚合**（谁在做哪道工序、涉及哪些切片）。
- 每张切片显示五序轨道、每序操作人/时间/依据、观察结论，并提供操作表单：
  完成当前工序（操作人、依据、下一负责人）、提交观察结论（合格；不合格需填缺陷、作废原因，
  可同时登记替代片或事后补登记）、交付批次。

## 接口

| 方法/路径 | 说明 |
| --- | --- |
| `POST /api/batches` | 登记批次，body：`{project,borehole,coreBox,depth,owner,slices:[{code,operator}]}` |
| `GET /api/batches` | 全部批次视图：进度、计数、下一负责人、待处理缺陷、交付门禁 |
| `POST /api/batches/:id/slices/:code/advance` | 推进一道工序：`{operator,basis,nextOperator?,expectedStage,reqId}` |
| `POST /api/batches/:id/slices/:code/observe` | 观察结论：`{conclusion: 合格\|不合格,operator,basis,defect?,reason?,replacementCode?,replacementOperator?}` |
| `POST /api/batches/:id/slices/:code/replacement` | 事后为不合格切片补登记替代片：`{replacementCode,operator?}` |
| `POST /api/batches/:id/deliver` | 交付批次（通过门禁才成功，重复交付返回 409） |

## 关键规则

- **严格顺序**：只能完成当前工序，一次前进一道；五序全部完成才允许观察下结论。
- **不合格**：必须登记缺陷与作废原因；切片立即作废，可当场或事后登记替代片，替代片从「取样」重新走五道。
- **交付门禁**：批次内不得有制片中/待观察切片、不得有未补替代片的作废片，
  且每张作废片的替代片必须已观察合格，否则交付返回 409 并给出逐项阻碍原因。
- **重复/过期推进只成功一次**：
  - 所有写操作经服务端互斥链串行化，并发请求逐个判定；
  - `reqId`（请求号）在一张切片内只消费一次，重复请求（含重启后重放）返回 `409 duplicate_request`；
  - `expectedStage`（客户端看到的期望工序下标）与当前工序不符返回 `409 stale_advance`，
    覆盖迟到的旧请求、双击重发、并发竞争；
  - 失败路径**不写入任何记录，状态不变**。
- **持久化**：全部状态写入 JSON 文件（临时文件 + 原子 rename），重启后完整恢复，
  包括工序记录、观察结论、作废/替代链、交付状态和已消费的请求号。

## 自动走通（demo.mjs）

脚本自行启动/停止服务（端口 4321，数据文件 `data/demo-run.json`，结束后删除），
覆盖：多切片五序推进（操作人/时间/依据）、过期请求失败且记录不变、
6 个并发重复请求只成功 1 个、同工序并发竞争只执行一次、合格/不合格观察、
缺陷与作废登记、替代片从第一道重做并复检合格、交付门禁的阻止与放行、
事后补替代片、重启后状态恢复与旧请求号重放拒绝。共 76 项断言。
